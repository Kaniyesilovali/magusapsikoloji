## Schema Nasıl Uygulanır?

`schema-markup.json` dosyasındaki kodu sayfanın `<head>` bölümüne ekleyin:

```html
<script type="application/ld+json">
  { ...ilgili schema bloğu buraya... }
</script>
```

**Hangi schema hangi sayfaya:**
- Tüm sayfalar → `MedicalBusiness + LocalBusiness` bloğu
- `/sss.html` ve `/en/faq.html` → `FAQPage` bloğu
- Hizmet sayfaları → ilgili `Offer` bloğu ayrıca eklenebilir

**Güncellenmesi gereken alanlar (schema-markup.json):**
- `telephone` — gerçek telefon numarası
- `streetAddress` — gerçek adres
- `postalCode` — posta kodu
- `image` — gerçek klinik fotoğrafı URL'i
- `sameAs` — sosyal medya profil URL'leri
